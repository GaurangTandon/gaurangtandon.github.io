Clipboard write timing probe

Measures how long each clipboard write takes to land in the OS clipboard, whether any write is silently dropped, and how long reads of plain, html and image content take. Nothing leaves this page: results stay in the table below until you copy them.

  1. Close other apps that might watch the clipboard only if asked to. Otherwise leave the machine exactly as it is day to day.
  2. Click Run. Allow clipboard access if the browser asks.
  3. Keep this tab focused until the status line says done (about 20 to 40 seconds). The write landed signal only fires while the page is focused.
  4. Click Select results, press Ctrl+C, and paste the text into your reply.

Per write

landed: ms from the write call until the browser's clipboardchange event, the OS write itself. promise: how long the write API took to resolve, which does not wait for the OS write. read: ms for a readText after the write (queues behind the write, so landed + a few ms when healthy). match: whether the read returned what we wrote. A red row is a dropped write: the read still shows the previous content.
